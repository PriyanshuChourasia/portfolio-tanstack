# Multi-Threading

Mutli threading can be seen as a computer's ability to multiple tasks at the exact same time by dividing program into smaller parts and independent jobs which
are called threads. [these threads can be called as an atoms of the multi-threading process].

`let's look at a dimension of single threading what is it ?` : single threading is a computer's ability to execute only one task at a time in a strict manner, step by step order.

Earlier computers used to have excalty one cpu core that processed one instruction at a time.

## Core

What is a core ?
it is a physical entity, a silicon-based engine inside a computer processor that reads and executes instructions. it is called the actual brain that does the math loads our apps and runs operating system.

a core is not just a solid piece of silicon; it is highly organized electronic workshop made of billions of microscopic switches called transistors.

now the essential components are [key components of core]
1. The Control unit
The control unit is responsible for fetching the code from RAM then after that it decodes it to understand what needs to be done and directs the flow of data inside the core.
2. ALU Arithmetic logic unit
3. Registers & L1/L2 cache
